# Artefato: Scripts de WhatsApp Business

Scripts prontos para configurar no WhatsApp Business ou treinar a equipe de atendimento.

## Quando usar
- Configurar mensagens automáticas do WhatsApp Business
- Padronizar o atendimento da equipe
- Treinar novo atendente

---

## Prompt para gerar scripts personalizados

```
Crie scripts de atendimento para WhatsApp para a empresa [NOME_DA_EMPRESA]:

**Segmento:** [SEGMENTO]
**Tom:** [Formal / Próximo e informal / Profissional com emojis]
**Horário de atendimento humano:** [ex: Seg-Sex, 8h às 18h]

Gere scripts para:
1. Mensagem de boas-vindas (primeiro contato)
2. Mensagem fora do horário de atendimento
3. Resposta para pedido de preço
4. Resposta para dúvida sobre prazo de entrega
5. Resposta para reclamação (antes de escalar para atendente)
6. Mensagem de follow-up (quando cliente some no meio da conversa)
7. Confirmação de agendamento
8. Lembrete de reunião/entrega (24h antes)

Para cada script: versão curta (mensagem automática) e versão humana (para o atendente expandir).
```

---

## Scripts prontos (personalize com seus dados)

### Boas-vindas
```
Olá! 👋 Seja bem-vindo(a) à [NOME_DA_EMPRESA]!

Sou o assistente virtual. Como posso ajudar?

1️⃣ Quero saber os preços
2️⃣ Tenho uma dúvida sobre meu pedido
3️⃣ Quero falar com um atendente
4️⃣ Outro assunto

Responda com o número da opção!
```

### Fora do Horário
```
Olá! 🌙

Recebemos sua mensagem, mas no momento nosso horário de atendimento humano está encerrado.

⏰ Atendemos: Seg-Sex, 8h às 18h | Sábados, 9h às 13h

Deixe sua mensagem aqui que retornamos assim que a equipe chegar! Se for urgente, envie email para [EMAIL].

Até logo! 😊
```

### Pedido de Preço
```
Oi! 😊 Obrigado pelo interesse!

Para te passar o melhor valor, me conta rapidinho:

📋 Qual produto/serviço te interessa?
📦 Qual a quantidade aproximada?
📍 Cidade (para calcular frete, se aplicável)?

Com essas informações, te passo o orçamento completo em até 2 horas! ⚡
```

### Follow-up (cliente sumiu)
```
Oi, [NOME]! Tudo bem? 👋

Vi que ficamos sem conversar — queria saber se conseguiu as informações que precisava ou se posso ajudar em algo mais.

Sem pressão, fico à disposição quando quiser! 😊
[NOME DO ATENDENTE] | [NOME_DA_EMPRESA]
```

### Confirmação de Agendamento
```
✅ Agendamento confirmado!

📅 Data: [DATA]
🕐 Horário: [HORÁRIO]
📍 Local: [ENDEREÇO ou "Online via [LINK]"]

Qualquer imprevisto, me avisa com antecedência para remarcarmos.

Até [DIA]! 👋
```
