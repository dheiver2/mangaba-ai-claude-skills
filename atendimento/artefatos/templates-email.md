# Artefato: Templates de Email de Atendimento

Biblioteca de templates prontos para as situações mais comuns de atendimento ao cliente.

## Quando usar
Cole o template no Claude pedindo para personalizar com os dados do seu cliente específico.

---

## Template 1 — Confirmação de Pedido/Contratação

```
Prompt: Personalize o template de confirmação de pedido para o cliente [NOME], que contratou [PRODUTO/SERVIÇO] em [DATA], com início previsto em [DATA_INÍCIO]. Empresa: [NOME_DA_EMPRESA].
```

**Template base:**
> Olá, [NOME]!
>
> Que ótimo tê-lo(a) conosco! ✅
>
> Confirmamos o recebimento do seu pedido:
> - Produto/Serviço: [ITEM]
> - Valor: R$ [VALOR]
> - Início: [DATA]
>
> Os próximos passos são:
> 1. [PASSO 1]
> 2. [PASSO 2]
>
> Qualquer dúvida, responda este email ou nos chame no WhatsApp: [NÚMERO]
>
> Seja bem-vindo(a)! 🎉

## Template 2 — Solicitação de Informações Adicionais

```
Prompt: Adapte o template de solicitação de documentos para o cliente [NOME], precisamos de [DOCUMENTOS NECESSÁRIOS] até [DATA_LIMITE] para [MOTIVO].
```

**Template base:**
> Olá, [NOME], tudo bem?
>
> Para darmos andamento ao seu [serviço/pedido], precisamos de algumas informações adicionais:
>
> 📎 **Documentos necessários:**
> - [ ] [DOCUMENTO 1]
> - [ ] [DOCUMENTO 2]
>
> **Prazo:** até [DATA] para não atrasar o início
>
> Pode enviar por email (resposta a este) ou WhatsApp ([NÚMERO]).
>
> Em caso de dúvidas, estou à disposição!

## Template 3 — Cobrança Amigável (1ª notificação)

```
Prompt: Personalize a cobrança amigável para o cliente [NOME], com fatura de R$ [VALOR] vencida em [DATA], chave PIX [CHAVE]. Tom amigável, sem pressão.
```

**Template base:**
> Olá, [NOME]!
>
> Passando para avisar que identificamos uma fatura em aberto:
>
> 💳 Valor: R$ [VALOR]
> 📅 Vencimento: [DATA]
>
> Se já realizou o pagamento, pode desconsiderar — às vezes o sistema demora a atualizar.
>
> Caso prefira, aqui está a chave PIX para facilitar:
> **[CHAVE PIX]**
>
> Qualquer dúvida, é só responder este email. 😊

## Template 4 — Encerramento de Atendimento

```
Prompt: Crie o encerramento de atendimento para o ticket [NÚMERO] do cliente [NOME], cujo problema era [PROBLEMA] e foi resolvido com [SOLUÇÃO].
```

**Template base:**
> Olá, [NOME]!
>
> Passando para confirmar que o seu atendimento foi concluído.
>
> ✅ **Resumo da resolução:**
> - Problema: [PROBLEMA RELATADO]
> - Solução aplicada: [O QUE FOI FEITO]
> - Prazo para ver o efeito: [se aplicável]
>
> Se o problema persistir ou tiver novas dúvidas, abra um novo chamado ou responda este email.
>
> Ficamos felizes em ajudar!
