# Artefato: Procedimento Operacional Padrão (SOP)

Gera um SOP completo e claro para documentar qualquer processo da empresa — fácil de seguir mesmo por quem nunca fez antes.

## Quando usar
- Documentar processos críticos que dependem de uma só pessoa
- Treinar novos colaboradores
- Padronizar qualidade entre diferentes turnos ou unidades
- Antes de automatizar um processo (documentar primeiro)

---

## Prompt

```
Você é um especialista em documentação de processos para PMEs brasileiras.

Crie um SOP (Procedimento Operacional Padrão) completo para o processo abaixo:

**Empresa:** [NOME_DA_EMPRESA]
**Nome do processo:** [EX: "Atendimento de novo lead via WhatsApp"]
**Responsável principal:** [CARGO]
**Backup (quem faz quando o responsável está ausente):** [CARGO]
**Frequência:** [Diário / Sob demanda / X vezes por semana]
**Objetivo do processo:** [O que deve ser alcançado ao final]

**Ferramentas utilizadas:**
[Ex: WhatsApp Business, Planilha Google, CRM HubSpot, email]

**Passo a passo atual:**
[Descreva cada etapa como é feita hoje]

**Pontos de atenção (erros comuns ou riscos):**
[Ex: esquecer de registrar no CRM, enviar proposta sem aprovação]

**Critério de sucesso:** [Como saber que o processo foi executado corretamente]

Gere o SOP com:
1. Cabeçalho (nome, versão, data, responsável, aprovador)
2. Objetivo e escopo
3. Glossário (termos que o novo colaborador pode não saber)
4. Pré-requisitos (o que precisa estar pronto antes de começar)
5. Passo a passo detalhado com:
   - Número da etapa
   - O que fazer (ação)
   - Como fazer (detalhe)
   - Ferramenta usada
   - Tempo estimado
   - Ponto de atenção ⚠️
6. Fluxograma textual
7. O que fazer se algo der errado (desvios e ações)
8. Checklist de conclusão
9. Histórico de revisões (tabela)
```
