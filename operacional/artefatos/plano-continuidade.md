# Artefato: Plano de Continuidade de Negócios

Gera um plano para manter a empresa operando em situações de crise — perda de funcionário-chave, queda de sistema, desastre ou pandemia.

## Quando usar
- Quando um único colaborador concentra conhecimento crítico
- Exigência de cliente corporativo ou certificação
- Revisão anual de riscos operacionais

---

## Prompt

```
Você é um especialista em gestão de riscos para PMEs brasileiras.

Crie um Plano de Continuidade de Negócios (PCN) básico para [NOME_DA_EMPRESA]:

**Operações críticas (sem as quais a empresa para):**
[Ex: atendimento ao cliente, emissão de NF, gestão financeira, produção do produto X]

**Pessoas-chave e o que só elas sabem fazer:**
[Ex: João — único que acessa o sistema financeiro; Maria — única que sabe configurar o e-commerce]

**Sistemas críticos:**
[Ex: ERP, CRM, servidor próprio, plataforma de e-commerce, internet banking]

**Riscos mais prováveis:**
[Ex: ausência de colaborador, queda de internet, ransomware, incêndio, falha no sistema de pagamento]

**Recursos disponíveis para contingência:**
[Ex: notebook backup, plano de internet de emergência (4G), backup em nuvem]

Para cada risco, gere:
1. Probabilidade e impacto (Matriz de Risco)
2. Tempo máximo de inatividade tolerável (RTO)
3. Plano de resposta imediata (primeiras 2 horas)
4. Plano de recuperação (até 72 horas)
5. Responsável pela ação
6. Contatos de emergência

Inclua também:
- Checklist de prevenção (o que fazer hoje para reduzir riscos)
- Política de backup de dados
- Comunicação com clientes em caso de interrupção
```
