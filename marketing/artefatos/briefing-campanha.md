# Artefato: Briefing de Campanha

Gera um briefing completo para passar a uma agência, freelancer ou para organizar uma campanha interna.

## Quando usar
- Contratar agência ou freelancer de marketing
- Organizar lançamento de produto/serviço
- Planejar campanha de datas comemorativas

---

## Prompt

```
Você é um gestor de marketing experiente em PMEs.

Crie um briefing de campanha completo para [NOME_DA_EMPRESA]:

**CAMPANHA:**
- Nome da campanha: [NOME ou "a definir"]
- Objetivo: [Vendas / Leads / Awareness / Retenção]
- Produto/serviço foco: [DESCREVA]
- Período: de [DATA_INÍCIO] a [DATA_FIM]
- Orçamento total: R$ [VALOR]

**PÚBLICO-ALVO:**
- Perfil primário: [ex: "Mulheres, 28-45 anos, donas de pequenos negócios, classe B/C"]
- Perfil secundário: [ex: "Gestores financeiros em empresas de 10-50 funcionários"]
- Onde encontrar esse público: [ex: "Instagram, grupos do WhatsApp de empreendedoras"]
- Dores e desejos: [DESCREVA]

**MENSAGEM CENTRAL:**
- Proposta de valor: [ex: "Economize 5h por semana com automação financeira"]
- Tom: [Urgência / Aspiracional / Educativo / Emocional]
- O que NÃO dizer: [ex: "Não comparar com concorrentes, não prometer resultados garantidos"]

**CANAIS PREVISTOS:**
[Instagram / Meta Ads / Email / WhatsApp / Google Ads / Influenciadores]

**ENTREGÁVEIS ESPERADOS:**
[Ex: "3 artes para feed, 5 stories, 1 email, 1 copy para anúncio"]

Gere um briefing executivo com todas as seções acima formatadas, mais:
- Referências visuais sugeridas (descreva estilo)
- Métricas de sucesso da campanha
- Cronograma de aprovações e publicações
- Checklist para a agência/freelancer
```
