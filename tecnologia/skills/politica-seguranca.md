# Política de Segurança da Informação

Gera uma política de segurança digital básica e prática para PMEs — protege dados de clientes, evita ataques e reduz riscos de LGPD.

## Quando usar
- Nunca teve política de segurança (hora de ter)
- Após qualquer incidente de segurança
- Exigência de cliente corporativo ou certificação
- Quando a equipe cresce e há mais pessoas com acesso a sistemas

---

## Prompt

```
Você é um especialista em segurança da informação para PMEs brasileiras.

Crie uma Política de Segurança da Informação básica e aplicável para [NOME_DA_EMPRESA]:

**Contexto:**
- Número de colaboradores: [NÚMERO]
- Modelo de trabalho: [Presencial / Híbrido / Remoto]
- Sistemas que usam: [Ex: Google Workspace, Notion, CRM, ERP, WhatsApp Business]
- Dados sensíveis que tratam: [Ex: CPF, dados bancários, dados de saúde, segredos comerciais]
- Já sofreram algum incidente? [Sim: descreva / Não]
- Tem departamento de TI? [Sim / Não — terceirizado / Não]

**Riscos que mais preocupam:**
[Ex: phishing, vazamento de dados de clientes, funcionário demitido com acesso, senha fraca, perda de notebook]

Gere a política com linguagem acessível (não técnica), contendo:
1. Uso aceitável de dispositivos e sistemas
2. Política de senhas (criação, troca, compartilhamento)
3. Controle de acesso (quem acessa o quê — princípio do menor privilégio)
4. Backup de dados (frequência, onde, quem é responsável)
5. O que fazer em caso de incidente (passo a passo)
6. Uso de dispositivos pessoais no trabalho (BYOD)
7. Redes Wi-Fi e trabalho remoto
8. Saída de colaboradores (revogação de acessos)
9. Treinamento e conscientização
10. Penalidades por descumprimento

Inclua também: checklist de segurança para o gestor revisar mensalmente.
```
