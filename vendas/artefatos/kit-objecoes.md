# Artefato: Kit de Respostas a Objeções

Gera respostas prontas e estratégicas para as objeções mais comuns no processo de vendas.

## Quando usar
- Treinar equipe de vendas
- Preparar para reunião com prospect difícil
- Quando a taxa de conversão está baixa e as objeções são sempre as mesmas

---

## Prompt

```
Você é um especialista em vendas consultivas para PMEs brasileiras.

Crie um Kit de Objeções completo para [NOME_DA_EMPRESA] que vende [PRODUTO/SERVIÇO] com ticket médio de R$ [VALOR]:

**Liste as objeções que mais ouve (em ordem de frequência):**
[Ex:
1. "Está muito caro"
2. "Preciso pensar / consultar meu sócio"
3. "Já tenho outro fornecedor"
4. "Não é o momento agora"
5. "Me manda mais informações por email"
6. "Quanto tempo leva para ver resultado?"]

**Contexto de venda:**
- Tipo de venda: [B2B / B2C / ambos]
- Canal: [Presencial / Videoconferência / WhatsApp]
- Quem decide: [Dono / Gestor / Comitê]

Para cada objeção, gere:
1. **O que o prospect realmente quer dizer** (interpretação real por trás da objeção)
2. **Resposta com método "Sente-Sentiu-Descobriu"** (validar → contar história → resolver)
3. **Pergunta de diagnóstico** (para entender a objeção antes de responder)
4. **Resposta direta** (para quando não há tempo para diagnóstico)
5. **Como identificar se é objeção real ou desculpa**
6. **Quando NÃO insistir** (prospect não é um bom fit)

Tom: empático, sem ser insistente. O objetivo é ajudar o prospect a tomar uma boa decisão, não vencer um debate.
```

---

## Exemplo de saída (Objeção: "Está muito caro")

**O que ele realmente quer dizer:** "Não vejo valor suficiente ainda" ou "Não tenho orçamento aprovado" ou "Preciso de justificativa para meu sócio"

**Pergunta de diagnóstico:**
> "Entendo. Só para eu entender melhor: o valor está fora do que vocês tinham de orçamento, ou é mais uma questão de ver se o retorno justifica?"

**Resposta (método Sente-Sentiu-Descobriu):**
> "Faz todo sentido se sentir assim — é um investimento relevante. Muitos dos nossos clientes sentiram o mesmo antes de contratar. O que descobriram depois é que [RESULTADO CONCRETO]. No caso de [CLIENTE SIMILAR], o retorno veio em [X semanas/meses]."

**Quando não insistir:** Se após 2 tentativas de descobrir a dor real o prospect continua só falando de preço sem mostrar interesse no resultado — ele não é seu cliente ideal agora.
