# Artefato: Playbook de Vendas

Gera um guia completo de vendas para padronizar o processo comercial, treinar novos vendedores e aumentar a conversão.

## Quando usar
- Contratar o primeiro vendedor
- Quando cada vendedor vende "do seu jeito" e os resultados são inconsistentes
- Revisão anual do processo comercial

---

## Prompt

```
Você é um diretor comercial especializado em PMEs brasileiras.

Crie um Playbook de Vendas completo para [NOME_DA_EMPRESA] que vende [PRODUTO/SERVIÇO]:

**Perfil do cliente ideal (ICP):**
- Segmento: [SEGMENTO]
- Tamanho: [EX: empresas de 10-100 funcionários]
- Cargo do decisor: [EX: dono, gerente financeiro]
- Dores mais comuns: [LISTE]
- O que os faz comprar: [LISTE]
- O que os faz não comprar: [LISTE]

**Processo de vendas atual:**
[Descreva as etapas do funil que vocês usam]

**Ticket médio:** R$ [VALOR]
**Ciclo médio de vendas:** [X dias]
**Taxa de conversão atual:** [X%] (ou "não sei")

**Principais objeções que você ouve:**
[Ex: "está caro", "preciso pensar", "não é o momento", "já tenho fornecedor"]

**Casos de sucesso para usar como prova social:**
[Descreva 2-3 clientes e resultados, ou "ainda não tenho documentado"]

Gere o Playbook com:
1. Perfil do cliente ideal (ICP) completo
2. Processo de vendas etapa a etapa (com critérios de avanço)
3. Script de qualificação (perguntas BANT: Budget, Authority, Need, Timeline)
4. Apresentação da empresa (elevator pitch — 30 segundos e 2 minutos)
5. Demonstração/reunião de diagnóstico (roteiro)
6. Como apresentar a proposta (estrutura e argumentos)
7. Tratamento das 5 principais objeções (pergunta → empathia → resposta → confirmação)
8. Técnicas de fechamento para PMEs brasileiras
9. O que fazer quando o cliente some (sequência de follow-up)
10. Métricas que cada vendedor deve acompanhar
```
