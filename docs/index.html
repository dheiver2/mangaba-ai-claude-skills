Começando agora

Usando em 4 passos

Sem instalação, sem configuração complexa. Só copiar, colar e preencher.

1

Clone o repositório

Baixe todos os arquivos de uma vez ou navegue pela pasta no GitHub.

2

Escolha o prompt

Cada área tem skills avulsas, agendadas e artefatos. Escolha o que precisa agora.

3

Preencha os campos

Substitua os campos em [COLCHETES] com os dados reais da sua empresa.

4

Cole no Claude

Abra claude.ai ou o Claude Code, cole o prompt preenchido e receba o resultado pronto.

# 1. Clone o repositório
git clone https://github.com/dheiver2/mangaba-ai-claude-skills

# 2. Agendar tarefa automática (precisa do Claude Code)
claude schedule create "Relatório diário de vendas" \
  --cron "0 9 * * 1-5" \
  --prompt-file vendas/scheduled/relatorio-vendas.md

# 3. Listar agendamentos ativos
claude schedule list

Acesse o repositório, clone e comece a usar hoje mesmo. É grátis e open source.
