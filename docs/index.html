Simples assim

Como usar em 4 passos

Sem instalação, sem configuração. Use direto no claude.ai ou com Claude Code para automações.

1

Escolha a skill

Navegue pelas 9 áreas e encontre o arquivo .md que resolve seu problema.

2

Copie o prompt

Cada arquivo tem um bloco "## Prompt" — copie ele inteiro.

3

Preencha os dados

Substitua os campos em [COLCHETES] com as informações reais da sua empresa.

4

Cole no Claude

Abra o claude.ai, cole o prompt preenchido e receba o resultado.

# Para automações com Claude Code CLI

# 1. Instalar
npm install -g @anthropic-ai/claude-code

# 2. Clonar o repositório
git clone https://github.com/dheiver2/mangaba-ai-claude-skills.git

# 3. Criar agendamento — relatório todo dia às 18h
claude schedule create \
  --name "relatorio-diario" \
  --cron "0 18 * * 1-5" \
  --prompt-file financeiro/scheduled/relatorio-diario-vendas.md
