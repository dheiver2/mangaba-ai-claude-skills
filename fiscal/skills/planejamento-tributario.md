# Planejamento Tributário Anual

Identifica oportunidades legais de redução de carga tributária para o próximo exercício fiscal.

## Quando usar
- Outubro a dezembro (planejamento para o ano seguinte)
- Quando os impostos representam mais de 15% do faturamento
- Antes de contratar, investir ou distribuir lucros

---

## Prompt

```
Você é um contador especializado em planejamento tributário para PMEs brasileiras.

Faça o Planejamento Tributário de [NOME_DA_EMPRESA] para [ANO]:

**Situação atual:**
- Regime tributário: [Simples / Lucro Presumido / Lucro Real]
- Faturamento projetado para [ANO]: R$ [VALOR]
- Margem líquida atual: [X%]
- Carga tributária atual (% do faturamento): [X%]
- Setor: [SEGMENTO]

**Estrutura societária:**
- Número de sócios: [NÚMERO]
- Pró-labore atual: R$ [VALOR]/mês total
- Distribuição de lucros: R$ [VALOR] no último ano

**Operações previstas para o ano:**
[Ex: abertura de filial, compra de equipamento, contratação de 3 pessoas, exportação para Argentina]

**Dúvidas ou situações específicas:**
[Ex: "Tenho imóvel que uso como sede — vale colocar na empresa?", "Posso contratar minha esposa?"]

Gere:
1. Diagnóstico da carga tributária atual vs benchmark do setor
2. Top 5 oportunidades de planejamento tributário legítimo
3. Para cada oportunidade: economia estimada, como implementar, prazo e riscos
4. Impacto da estrutura de pró-labore vs distribuição de lucros
5. Benefícios fiscais aplicáveis (isenções, incentivos, MEI para atividade paralela)
6. Calendário fiscal do ano com datas críticas
7. Perguntas para levar ao seu contador

⚠️ Este planejamento é orientativo. Implemente apenas com validação do seu contador/advogado tributarista.
```
